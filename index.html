Data Architecture

LexaForte TMX Purifier

Proprietary cleaning engine covering ~20 scripts: Latin, Cyrillic, CJK, Ethiopic and more. Noise is removed before a single training step runs.

Layer 01 2M segs / 5s

Vectorized Fast-Pass

Rust / C++ multi-threaded pass that vaporizes control characters, PUA Unicode, broken text, duplicate segments and OCR artefacts.

~2,000,000 rows per 5 seconds
Layer 02 Multi-core

Multiprocess Heuristics

Source and target checked together across CPU cores: number consistency, script-leak rates, bracket symmetry and tag balance.

HTML / XML tags and placeholders normalized
Layer 03 Zero write

Synthetic Dry-Run

Purification is simulated with nothing written to disk. Every kept or killed pair is logged with a reason, then locked into a client JSON rule set.

Company-specific JSON policy for the real run
